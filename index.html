    How to use Work Desk

    Quick start

    1. Pick a day on the calendar, or use the arrows at the top of the desk.
    2. Choose Task or Note, type your entry, and click Add.
    3. Everything saves automatically in your browser.

    To move your data to another computer, use Export backup in the sidebar (under More) and Import backup on the new machine.

    What it does

    • Daily desk — tasks and notes organized by day in New / Active / Done columns
    • Work & Personal — separate lists, toggled in the sidebar
    • Search — find tasks and notes; focus the search box and use the Both chip to search Work and Personal together
    • Carry forward — bring unfinished tasks into today; use the ▾ menu on the carry button to turn on Auto carry each day
    • Recurring tasks — templates that auto-add on schedule
    • Insights — weekly, monthly, and yearly stats
    • Archive — export older days to JSON files to keep the app fast
    • Themes — light and dark presets; Synthwave, Cyberpunk, Outrun, and Vaporwave each have both variants
    • Backup / restore — export or import your full data as JSON

    Working with tasks

    • Shelving — drag a task to Shelved when it isn't done but isn't today's focus; unshelf it later from the same column
    • Comments — click the speech-bubble icon to add notes, updates, or links without changing the task title
    • Move to another day — use the calendar icon to reschedule; the task leaves today and appears on the date you pick
    • Send to Work / Personal — the arrow icon moves a task or note to the other list
    • Notes vs tasks — notes are plain entries for the day; only tasks use the New / Active / Done board

    Navigation

    • Calendar — pick any day; dots mean data exists; red badges on past days show open tasks left behind
    • Arrow buttons — step day by day at the top of the desk
    • Today — click Back to today beside the date to return; a Today badge shows when you're on the current date; a Work or Personal badge shows which list you're viewing
    • Week strip — on narrower screens, a compact week picker appears above the board
    • Progress bar — shows task mix for the day; colored labels under the bar explain each segment

    Recurring tasks

    • Open via the Recurring tab next to Task and Note
    • Templates auto-add on the schedule you set (daily, weekly, on specific days, etc.)
    • Injected tasks show a 🔁 badge on the card
    • Edit or delete templates in the recurring panel; changes apply to future injections, not past copies

    Archive & backup

    • Backup — a full snapshot of all your data; use when moving machines or keeping a safety copy
    • Archive — exports days older than 6 months to JSON and removes them from the app to keep it fast; runs automatically when you open the app if anything is eligible
    • Archived data isn't lost, but no longer appears in daily search until you restore it manually
    • Import — Merge combines with existing data; Replace wipes current data first (use with care)

    Data & privacy

    Everything stays in your browser (localStorage) unless you export or archive it. Clearing site data for this page will remove your tasks.

    • Data is per browser, per device — Work on this PC and Work on your laptop are separate unless you export/import
    • Don't clear site data for this page unless you've exported first
    • Opening the file directly (file://) works; bookmark the page so you can return to the same data

    Mobile & touch

    • Task text gets the full width; action icons sit in a row below (like comments)
    • Tap Start on New tasks, or press and drag a task into another column
    • Tap the checkbox to complete a task
    • Tap the pencil icon to edit — double-tap is unreliable on touch screens
    • The week strip above the board replaces the sidebar calendar on narrower screens

    Tips

    • Double-click an item to edit it (desktop); on touch, tap the pencil icon
    • Drag tasks between columns or reorder within a column (desktop)
    • On desktop, hover a task row to reveal action icons; on touch they are always shown
    • Click Aa next to the input to show bold, italic, and underline formatting.
    • Use Ctrl+B, Ctrl+I, and Ctrl+U (or Cmd on Mac) while editing.
    • Press Escape to cancel an edit.
    • After deleting, click Undo in the toast before it disappears (deletes ask for confirmation first)
    • Press Ctrl+Enter or Cmd+Enter in the add box to submit without clicking Add
    • Use the sidebar collapse button to give the board more room.
    • Completed tasks show a small confetti burst.

    Keyboard shortcuts

    • Add task/note — Ctrl/Cmd + Enter (in the add box)
    • Bold — Ctrl/Cmd + B
    • Italic — Ctrl/Cmd + I
    • Underline — Ctrl/Cmd + U
    • Cancel edit — Escape
