      How to use Work Desk

      Quick start

      1. Sign in with your email to enable cloud sync across devices.
      2. Pick a day on the calendar, or use the arrows at the top of the desk.
      3. Choose Task or Note, type your entry, and click Add.
      4. Everything saves automatically and syncs to the cloud within a few seconds.

      What it does

      • Daily desk — tasks and notes organized by day in New / Active / Done / Shelved columns
      • Work, Personal & Projects — three separate contexts, toggled in the sidebar
      • Projects — a dedicated space for long-running ideas, collaborations, or side projects not tied to daily tasks
      • Comments & updates — add threaded notes under tasks; notes get timestamped updates the same way
      • Search — find tasks and notes across any day; use the Both chip to search Work and Personal together
      • Carry forward — bring unfinished tasks into today; use the ▾ menu on the carry button to turn on Auto carry each day (pulls open tasks from all past days, not just yesterday)
      • Recurring tasks — templates that auto-add on a schedule you define
      • Insights — weekly, monthly, and yearly stats with a daily breakdown chart and activity heatmap
      • Auto-pruning — days older than 1 year are automatically removed from the local cache on startup to keep the app fast; your full history is always preserved in the cloud
      • Themes — light and dark presets including Synthwave, Cyberpunk, Outrun, Vaporwave, Forest, and more
      • Cloud sync — your data is backed up to the cloud and available on any device you sign in to; devices merge changes automatically
      • Installable — install as a home screen app on mobile or desktop for a native app experience

      Task & note cards

      • Action bar — common actions sit along the bottom of each card: edit, move, and comment / add update
      • Overflow menu (⋮) — less common actions live here: delete, convert, send to Work/Personal, shelve/unshelve, and start (move to Active)
      • Convert — switch a task into a note or vice versa from the overflow menu
      • Shelving — move a task to Shelved when it isn't done but isn't today's focus; unshelf it later from the Done/Shelved column
      • Move to another day — reschedule a task; it leaves today and appears on the new date; a confirmation toast confirms where it went
      • Send to Work / Personal — moves a task or note to the other context list
      • Completed tasks — fade to 62% opacity and show strikethrough; hover to see them clearly

      Comments & updates

      • Tasks — click comment on a card to open the thread; add timestamped comments with bold, italic, underline, and bullet formatting
      • Notes — use add update for the same threaded follow-ups (handy for living documents)
      • Indent — comments sit slightly indented under the card so they read as replies, not another task
      • Keep comments open — in Customize (⊟), turn this on so opening comments on one task doesn't collapse another; click comment again to close just that thread
      • Multi-line — press Enter for new lines; numbered lists like 1) and bullets stay formatted when you save

      Projects

      • What it's for — capture notes and tasks for long-running projects, side ideas, or collaborations that don't fit the daily workflow
      • Create a project — click the Projects tab in the sidebar, then click + to add a new project
      • Notes & tasks — each project has its own notes and tasks; notes support updates (like comments) to track progress over time
      • Cloud sync — projects sync to the cloud alongside your Work and Personal data

      Board layout

      • Card density & theme — use the customize button (⊟) near the date to switch between Comfortable and Compact layouts and to change the color theme
      • Keep comments open — in the same customize menu, turn this on so opening comments on one task doesn’t collapse another
      • Auto-collapse Completed — optionally collapse the Completed list after a count you choose (3–20); tap the heading to expand
      • Left accent bar — each card has a colored left border matching its column (New = accent, Active = hover accent, Done = done color, Notes = muted)
      • Progress bar — the segmented bar above the board shows today's task mix; hover segments for counts
      • Column counts — the Done/Shelved header shows completed / shelved counts separately
      • Drag tasks between columns or reorder within a column (desktop)

      Navigation

      • Calendar — pick any day; dots mean data exists; red badges on past days show open tasks left behind
      • Arrow buttons — step day by day at the top of the desk
      • Today — click Back to today beside the date to return instantly
      • Week strip — on narrower screens a compact week picker appears above the board; use < / > to jump week by week (Monday-aligned)

      Recurring tasks

      • Open via the Recurring tab next to Task and Note in the add form
      • Templates auto-add on the schedule you set (daily, weekly, specific days, etc.)
      • Injected tasks show a 🔁 badge on the card
      • Edit or delete templates from the recurring panel; changes apply to future injections only

      Insights

      • Switch between Week, Month, and Year views
      • Bar chart shows completed, shelved, open (new today), and open (carried over) per period
      • Activity heatmap (year view) — GitHub-style grid showing completion intensity by day; color adapts to your active theme
      • Day-by-day detail table shows full breakdown including carried-over and newly created counts

      Cloud sync & data

      • Sign in with email to enable sync; your data is stored in the cloud and isolated per account
      • Continue offline — you can use the desk without signing in; data stays in this browser only and can be wiped if site data is cleared. Use Sign in at the bottom of the sidebar when you’re ready to create an account or sync
      • Synced preferences — theme, card density, Keep comments open, Auto-collapse Completed, and Auto carry follow your account across devices
      • The sync status icon (☁️ / 🔄 / ✓ / !) appears at the bottom of the sidebar next to your account email
      • Use Sign out at the bottom of the sidebar to switch accounts
      • Changes push to the cloud a few seconds after you edit; focusing the tab or waiting a few minutes also pulls updates from other devices
      • Opening on a new device: sign in and your history loads automatically (devices merge rather than overwrite)
      • Backup / restore — Export backup and Import backup in the sidebar for a local JSON safety copy (includes Projects when you're in that context)
      • Repair duplicates — cleans duplicate task IDs within a day and across days, and collapses same-day copies of the same recurring task if sync ever left extras behind
      • Auto-pruning — on each app startup, days older than 1 year are silently removed from the local cache; full history remains in the cloud

      Mobile & PWA

      • Install as a home screen app: on Chrome/Edge tap Install and create shortcut (or address bar install icon on desktop)
      • On iPhone/Safari: tap Share → Add to Home Screen
      • Once installed, opens in its own window without browser chrome and works offline
      • Use the action links under each card (edit / move / comment) and the ⋮ overflow menu for the rest
      • Tap the checkbox to complete a task
      • The add bar sticks to the bottom of the screen so you can capture a task without scrolling up
      • The week strip above the board replaces the sidebar calendar on smaller screens
      • Account status, Sign in / Sign out, and Export/Import stay available in the sidebar on mobile

      Tips

      • Double-click a task or comment to edit it on desktop
      • Click Aa next to the input box to show bold, italic, underline, and bullet formatting buttons
      • After deleting, click Undo in the toast before it disappears
      • Press Ctrl+Enter (or Cmd+Enter) in the add box to submit without clicking Add
      • Use the sidebar collapse button (‹) to give the board more room
      • Completing a task triggers a small confetti burst
      • The theme picker adapts the entire UI including the activity heatmap and progress bar colors

      Keyboard shortcuts

      • Add task/note — Ctrl/Cmd + Enter
      • Bold — Ctrl/Cmd + B
      • Italic — Ctrl/Cmd + I
      • Underline — Ctrl/Cmd + U
      • Cancel edit / close menu — Escape

      Possible future improvements

      • Google Assistant integration — "Hey Google, what are my tasks for today?" / "Hey Google, add a task to do xyz" via a Google Actions webhook connected to the Supabase backend
      • Data encryption — opt-in PIN or passphrase-based AES-256 encryption of stored data so the Supabase DB owner cannot read tasks in plain text; PIN (4–6 digits) blocks casual viewing, a full passphrase blocks determined attacks
